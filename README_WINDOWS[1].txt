AutoBot - Windows build
=======================

1. Install Python 3.10+ from python.org (tick "Add python.exe to PATH";
   keep "tcl/tk and IDLE" ticked). Google Chrome is optional - if it is not
   installed, AutoBot uses the Chromium that setup.bat downloads.
2. Copy this whole folder to the laptop.
3. Double-click setup.bat (once; needs internet, takes a few minutes).
4. Double-click run.bat.

Your DeepSeek key is in the file named .env (hidden files may need
"Show hidden items" in Explorer). Keep it private - anyone with the folder has the key.
Delete .chromium_profile and logs if you ever copy this folder onward: they hold
login sessions and page snapshots.
